# Урок 2. Сборка и запуск сайта в Podman

В ветке `lesson_2` сохранён результат второго занятия. Готовый `index.html` содержит страницу сайта, а `Containerfile` описывает образ nginx с этой страницей. Откройте [методичку занятия](docs/podman-practice.docx), чтобы повторить практику, или запустите готовую версию `v1`, чтобы продолжить лабораторную работу.

## Запуск на Fedora

Выполните команды в терминале под своей обычной учётной записью. Имя папки `Podman-lesson-2` позволяет сохранить отдельную копию урока.

```bash
git clone --branch lesson_2 --single-branch https://github.com/BorsalinoK1zaru/Podman-lessons.git Podman-lesson-2
cd Podman-lesson-2
./start.sh
```

Откройте [http://127.0.0.1:8091/](http://127.0.0.1:8091/) в браузере на том же компьютере. На странице должен появиться заголовок «Моя страница в контейнере».

`git clone` получает готовые файлы проекта. `./start.sh` собирает локальный образ `localhost/course-site:v1` и запускает контейнер `podman-lessons-site`. Скрипт использует локальный `docker.io/library/nginx:stable-alpine`, если он уже есть. При первом запуске без локального образа Podman скачает его с Docker Hub.

На учебной Fedora нужны Git и Podman. Редактировать файлы можно в nano или любом текстовом редакторе. Если на компьютере отсутствует нужная программа и вам разрешена установка, используйте `sudo dnf install git podman nano`. Команды Podman запускайте без `sudo`, чтобы использовать своё хранилище образов и контейнеров.

## Что делать дальше

Оставьте первую версию запущенной и откройте [продолжение лабораторной работы](docs/laboratornaya.md). Вы добавите страницу «О сайте», соберёте образ с тегом `v2` и проверите обе версии в браузере.

| Где | Что лежит |
| --- | --- |
| `index.html`, `Containerfile` | Исходники готовой версии сайта |
| `start.sh` | Локальная сборка и запуск первой версии |
| [Практикум по Podman](docs/podman-practice.docx) | Образ, контейнер, порты, журнал и сборка |

## Проверка и остановка

```bash
podman ps
podman port podman-lessons-site
podman logs --tail 15 podman-lessons-site
```

Если порт 8091 занят, запустите `./start.sh 8092` и откройте порт 8092. Если `podman-lessons-site` уже работает, используйте адрес из `podman port podman-lessons-site`. Чтобы освободить порт, остановите контейнер:

```bash
podman stop podman-lessons-site
```

Скрипт запускает контейнер с параметром `--rm`, поэтому после остановки Podman удалит этот экземпляр. Исходники и локальный образ останутся доступны.

Если образ не загружается из Docker Hub, можно получить учебный архив `nginx-course.tar` и импортировать его командой `podman load -i nginx-course.tar` из папки с архивом. Проверьте в `podman images`, что загрузился `docker.io/library/nginx:stable-alpine` для вашей архитектуры.
