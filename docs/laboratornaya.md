# Вторая версия сайта в Podman

Начните с готовой первой версии из [README](../README.md). Убедитесь, что она открывается в браузере, и оставьте контейнер запущенным. Работайте из корня клона, где уже находятся `index.html` и `Containerfile`.

## Добавьте страницу

Создайте рядом с `index.html` файл `about.html`. Можно взять разметку первой страницы за основу. Поставьте заголовок «О сайте» и добавьте два предложения о его назначении. Добавьте ссылку на главную:

```html
<a href="index.html">На главную</a>
```

В `index.html` после описания добавьте ссылку на вторую страницу:

```html
<a href="about.html">О сайте</a>
```

Добавьте в конец `Containerfile` строку, которая включает новую страницу в образ:

```dockerfile
COPY about.html /usr/share/nginx/html/about.html
```

## Соберите и запустите v2

```bash
podman build --pull=missing -t localhost/course-site:v2 -f Containerfile .
podman run --pull=never --rm -d --name podman-lessons-site-v2 -p 127.0.0.1:8182:80 localhost/course-site:v2
```

Откройте [http://127.0.0.1:8182/](http://127.0.0.1:8182/). По ссылке «О сайте» должна открываться вторая страница, а по ссылке «На главную» — первая. В первоначальной версии на порту 8091 (или на порту, который вы выбрали при запуске) новой ссылки ещё нет. Этот контейнер запущен из прежней сборки.

Если маршрут возвращает 404, сверьте имя файла в ссылке, строку COPY и порт в браузере. Если порт 8182 занят, в команде запуска замените его, например, на 8282. Порт nginx внутри контейнера оставьте 80. После дальнейшей правки файлов пересоберите образ, остановите предыдущий экземпляр v2 и создайте новый.

Когда закончите, остановите свои учебные контейнеры:

```bash
podman stop podman-lessons-site podman-lessons-site-v2
```
